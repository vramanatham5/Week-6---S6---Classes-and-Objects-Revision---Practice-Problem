# Week 1 Java Assignment

This repository contains five Java programs demonstrating arrays, loops, strings, and basic data analysis.

## Programs

1. **Exam Hall Seat Duplication Checker**
   - Finds duplicated seat numbers using arrays and loops.
2. **Typing Speed Test Accuracy Checker**
   - Calculates character accuracy and reports the first mismatch position.
3. **Traffic Signal Streak Analyzer**
   - Finds the longest continuous signal-color streak.
4. **Warehouse Inventory Balancer**
   - Compares section totals and finds the highest inventory quantity.
5. **Movie Review Word Length Profiler**
   - Counts short, medium, and long words in a review.

## Compile

From the repository root, run:

```powershell
javac Question1_SeatDuplicationChecker\SeatDuplicationChecker.java
javac Question2_TypingAccuracyChecker\TypingAccuracyChecker.java
javac Question3_TrafficStreakAnalyzer\TrafficStreakAnalyzer.java
javac Question4_WarehouseInventoryBalancer\WarehouseInventoryBalancer.java
javac Question5_MovieReviewProfiler\MovieReviewProfiler.java
```

Each command creates a `.class` file in its corresponding folder.

## Run

```powershell
java -cp Question1_SeatDuplicationChecker SeatDuplicationChecker
java -cp Question2_TypingAccuracyChecker TypingAccuracyChecker
java -cp Question3_TrafficStreakAnalyzer TrafficStreakAnalyzer
java -cp Question4_WarehouseInventoryBalancer WarehouseInventoryBalancer
java -cp Question5_MovieReviewProfiler MovieReviewProfiler
```
