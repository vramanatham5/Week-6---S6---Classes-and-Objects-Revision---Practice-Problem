# Week 6: Classes and Objects Revision

Java practice problems covering classes, objects, constructors, encapsulation, object references, and static members.

## Exercises

- `q1`: Stores and prints placement records using a class and an array of objects.
- `q2`: Implements a mess wallet with validation, top-ups, deductions, and balance tracking.
- `q3`: Demonstrates constructor overloading and total course-credit calculation.
- `q4`: Demonstrates object references and reference equality.
- `q5`: Demonstrates static fields, static methods, and shared student counting.

## Compile and Run

From the repository root, compile and run an exercise with:

```powershell
javac q1\in.java
java -cp q1 in
```

Replace `q1` with `q2`, `q3`, `q4`, or `q5` as needed.
